# Huddle — desktop app

Installers for the Huddle desktop client. Download the latest release from the
[Releases](https://github.com/CodeDigitize/huddle-releases/releases/latest) page:

| Platform | File |
| --- | --- |
| macOS (Apple Silicon, M1–M4) | [`Huddle-mac-arm64.dmg`](https://github.com/CodeDigitize/huddle-releases/releases/latest/download/Huddle-mac-arm64.dmg) |
| Windows (64-bit) | [`Huddle-Setup-x64.exe`](https://github.com/CodeDigitize/huddle-releases/releases/latest/download/Huddle-Setup-x64.exe) |

## macOS first launch

Releases from 1.0.6 on are signed with a Developer ID and notarized by Apple,
so they open without warnings. Only the older 1.0.x builds needed
right-click → **Open** on first launch.

## Updates

The app checks this repository for new releases and offers to install them.
